## How to read this report

The HTTP checker records each response and redirect hop, uses a bounded HEAD request followed by a small ranged GET when needed, refuses local/private-network targets, and follows only HTTPS redirects. HTTP 401/403/406/418/429, 5xx responses, timeouts, bot challenges, suspicious parking pages and other ambiguous results are **blocked / inconclusive**, not broken. Only clear 404/410 responses are classified broken. Cross-host redirects are explicitly flagged for relevance review. A successful HTTP response is not a safety, legal, licensing or quality guarantee. A failed or incomplete audit run is not written; when an individual request is inconclusive, the latest status is shown while previous checks remain in the entry history. Run `npm run check:links:update` to refresh the stored audit.
